# Stram Desktop

The official Windows desktop app for [stram.lol](https://stram.lol).

## Download

Get the latest installer from the [Releases page](https://github.com/negrosuck45-bit/stram-desktop/releases/latest).

- **Windows 10/11 x64**
- Installer: `Stram-Setup-1.0.1.exe`
- The app loads the live site, so site updates appear without reinstalling.

## Install

1. Download `Stram-Setup-1.0.1.exe`.
2. Run it and choose an install folder.
3. The build is unsigned, so Windows SmartScreen may say "Unknown publisher". Click **More info** → **Run anyway**.
